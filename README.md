## The entry

One sentence, 191 characters, written to convince a friend who has never coded to let an AI agent build their first app idea on make.fun:

> Describe your app idea in plain words, watch an AI agent build a working first version while you finish your coffee, and if you don't love it you just don't ship it — trying it costs nothing.

## How it works

`main.py` writes that single sentence to `/output/entry.txt`. Nothing else is
produced, no network is used, and the output is byte-identical on every run.

```sh
python3 main.py
cat /output/entry.txt
```
